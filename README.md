# Projekt inżynierski — Informatyka

Materiały do laboratoriów przedmiotu **Projekt inżynierski** dla III roku kierunku Informatyka, semestr zimowy 2026/2027.

Strona kursu: [index.md](index.md). Plan zajęć i wszystkie instrukcje znajdują się w katalogu [`2026-2027/`](2026-2027/README.md).

Materiały źródłowe i robocze przechowywane lokalnie w `priv/` są ignorowane przez Git.

Wzorcowe ilustracje Gantta są generowane z danych zadań poleceniem `python scripts/generuj_przyklady_gantta.py`. Skrypt przelicza daty, zapasy i obciążenia oraz zapisuje zgodne kopie SVG w `2026-2027/lab4/img/`, `2026-2027/lab4/gantt/img/` i `img/`. Przy zmianie instrukcji Gantta należy również zaktualizować jej kopię w `index.md` (różni je tylko permalink).
